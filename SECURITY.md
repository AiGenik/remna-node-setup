# Безопасность

Сообщите об уязвимости приватно через **Security → Report a vulnerability** на GitHub. [Открыть форму](https://github.com/AiGenik/remna-node-setup/security/advisories/new)

Укажите версию Remna Node Setup, версию Ubuntu, затронутую команду и шаги для воспроизведения. Перед отправкой удалите из примеров реальные пароли, ключи Remnawave и токены.

Обычные ошибки и вопросы по установке можно обсуждать в [GitHub Issues](https://github.com/AiGenik/remna-node-setup/issues).
