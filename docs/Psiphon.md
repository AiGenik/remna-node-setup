# Psiphon

Psiphon даёт ноде отдельный выход через SOCKS5 на `127.0.0.1:1080`. Для него нужен Docker Engine 28 или новее. На новом VPS мастер поставит Docker. Адрес и порт доступны только на VPS. [vps-psiphon](https://github.com/Chara-Freedom/vps-psiphon) · [Публикация портов Docker](https://docs.docker.com/engine/network/port-publishing/)

1. В мастере **[1] Всё под ключ** Psiphon для Gemini включён по умолчанию — достаточно выбрать регион (или оставить `auto`) и порт (по умолчанию `1080`). Для готовой ноды откройте **[2] Установка и настройка по частям → [8] Psiphon для Gemini**.
2. Выберите регион или оставьте «авто». Укажите свободный локальный SOCKS-порт.
3. Проверьте статус командой `sudo remna-node-setup psiphon status` (или через **[3] → [3] Живой тест: Gemini, YouTube и Certbot**).

Управляемый Psiphon входит в «Обновить всё» и автообновления. При установке и обновлении мастер автоматически подтягивает последний стабильный релиз `Chara-Freedom/vps-psiphon` и проверяет наложение безопасных патчей (`--bind-loopback`, отключение HTTP-прокси); если структура апстрима несовместима, используется проверенная встроенная версия. Ручная установка `vps-psiphon` сохраняет своё управление. Каждая нода поднимает собственный изолированный `vps-psiphon` на `127.0.0.1:1080` и не пересылает трафик через другие ноды. При смене региона через `vps-psiphon region КОД` (например `CA` или `NL`) `status`, `doctor` и `update` учитывают активный `EGRESS_REGION` из `/etc/default/vps-psiphon`.

## Шаблон Gemini

В «Порты и защита → Gemini · Шаблон для Remnawave» укажите локальный адрес VPS, на котором Xray принимает соединения. Мастер предложит IP исходящего интерфейса. Для общей конфигурации уточните адрес, если у ноды несколько IP.

```bash
sudo remna-node-setup psiphon profile IP_НОДЫ
```

В панели Remnawave откройте нужный Config Profile, например XHTTP или GRPC. Перенесите элементы `outbounds` и `routing.rules` из шаблона в существующие массивы. Правила Gemini должны стоять раньше общего правила маршрутизации. Если теги уже существуют, обновите их. При использовании одного профиля на нескольких нодах добавьте адрес новой ноды в `localIP` обоих правил.

Если профиль уже настроен для других нод, сохраните его как `profile.json` на VPS и выполните команду. Мастер добавит адрес текущей ноды в оба правила Gemini с сохранением существующих адресов. Затем вставьте обновлённый JSON в редактор профиля Remnawave.

```bash
umask 077
sudo remna-node-setup psiphon profile-merge < profile.json > profile-new.json
```

Шаблон отправляет TCP только к указанным хостам Gemini (`gemini.google.com`, `aistudio.google.com`, `generativelanguage.googleapis.com` и др.) через `psiphon-out` и блокирует UDP/443 к тем же хостам, чтобы клиент повторил запрос по TCP. Остальной трафик (включая YouTube) остаётся на прямом выходе ноды (`DIRECT`). `localIP` ограничивает изменения выбранной нодой. После сохранения проверьте подключение одного клиента. [Маршрутизация Xray](https://xtls.github.io/en/config/routing.html)
