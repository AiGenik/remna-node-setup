# Psiphon

Psiphon даёт ноде отдельный выход через SOCKS5 на `127.0.0.1:1080`. Для него нужен Docker Engine 28 или новее. На новом VPS мастер поставит Docker. Адрес и порт доступны только на VPS. [vps-psiphon](https://github.com/Chara-Freedom/vps-psiphon) · [Публикация портов Docker](https://docs.docker.com/engine/network/port-publishing/)

1. Откройте «Порты и защита → Настроить Psiphon».
2. Выберите регион или оставьте «авто». Укажите свободный локальный SOCKS-порт.
3. Проверьте статус командой `sudo remna-node-setup psiphon status`.

Управляемый Psiphon входит в «Обновить всё» и автообновления. Проверенная версия установщика и digest образа поставляются с релизом Remna Node Setup. Ручная установка vps-psiphon сохраняет своё управление.

## Шаблон Gemini

В «Порты и защита → Шаблон Gemini для Psiphon» укажите локальный адрес VPS, на котором Xray принимает соединения. Мастер предложит IP исходящего интерфейса. Для общей конфигурации уточните адрес, если у ноды несколько IP.

```bash
sudo remna-node-setup psiphon profile IP_НОДЫ
```

В панели Remnawave откройте нужный Config Profile, например XHTTP или GRPC. Перенесите элементы `outbounds` и `routing.rules` из шаблона в существующие массивы. Правила Gemini должны стоять раньше общего правила маршрутизации. Если теги уже существуют, обновите их. При использовании одного профиля на нескольких нодах добавьте адрес новой ноды в `localIP` обоих правил.

Шаблон отправляет TCP к указанным хостам Gemini через Psiphon и блокирует UDP/443 к тем же хостам, чтобы клиент повторил запрос по TCP. `localIP` ограничивает изменения выбранной нодой. После сохранения проверьте подключение одного клиента. [Маршрутизация Xray](https://xtls.github.io/en/config/routing.html)
