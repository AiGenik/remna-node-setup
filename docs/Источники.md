# Источники

- RemnaSetup. Изучены состав установки, Docker Compose, варианты self-steal, BBR, WARP и сценарий обновления. [Исходники на 55495e9](https://github.com/Capybara-z/RemnaSetup/tree/55495e9783b8388a48e6580ff4c2c26a3eafa08f)
- «Решала». Изучены устройство меню, управление UFW и Fail2Ban, бэкапы, обновление и диагностика. Дашборд, управление флотом, WARP и шейпинг оставлены для следующих версий. [Исходники на 079365e](https://github.com/DonMatteoVPN/Reshala-Remnawave-Bedolaga/tree/079365e65abd50f752ecf0a16eb3a063142f42b5)
- TrafficGuard. Изучены восстановление ipset, цепочки UFW и порядок применения списка. Проверенные ссылки выбираются отдельно при каждой установке или обновлении. [Текущий стабильный релиз](https://github.com/dotX12/traffic-guard/releases/latest) · [Список сканеров](https://github.com/shadow-netlab/traffic-guard-lists) · [Проверка файла релиза по SHA-256](https://docs.github.com/en/rest/releases/assets)
- Официальная документация. [Remnawave Node](https://docs.rw/install/remnawave-node/) · [Docker host networking](https://docs.docker.com/engine/network/drivers/host/) · [Docker и фильтрация пакетов](https://docs.docker.com/engine/network/packet-filtering-firewalls/) · [Caddy Automatic HTTPS](https://caddyserver.com/docs/automatic-https)
- Self-steal с Nginx. Локальная схема сверена с RemnaSetup. Для выпуска и продления через HTTP-01 используется Certbot webroot. [Шаблон RemnaSetup](https://github.com/Capybara-z/RemnaSetup/blob/55495e9783b8388a48e6580ff4c2c26a3eafa08f/data/nginx/selfsteal.conf) · [Certbot Webroot](https://eff-certbot.readthedocs.io/en/stable/using.html#webroot)
- Источники подсказок мастера. Названия полей взяты из интерфейса панели, строки порта и ключа сверены с обоими шаблонами. [Карточка ноды](https://github.com/remnawave/frontend/blob/20fabab0d788af97273d646614c6b9980f6f29d1/src/shared/_modals/nodes/create-node-modal/create-node-steps/create-node-step-1-connection.tsx) · [Compose панели](https://github.com/remnawave/frontend/blob/20fabab0d788af97273d646614c6b9980f6f29d1/src/shared/_modals/nodes/create-node-modal/create-node-steps/copy-docker-compose.widget.tsx) · [Compose RemnaSetup](https://github.com/Capybara-z/RemnaSetup/blob/55495e9783b8388a48e6580ff4c2c26a3eafa08f/data/docker/node-compose.yml)
- Отдельная установка контейнера используется в RemnaSetup. «Решала» запрашивает дополнительные входящие порты. Remnawave настраивает служебный порт в карточке ноды, клиентский порт в профиле Xray и в Host. [Установка контейнера в RemnaSetup](https://github.com/Capybara-z/RemnaSetup/blob/main/scripts/remnanode/install-node.sh#L109-L130) · [Настройка firewall в «Решале»](https://github.com/DonMatteoVPN/Reshala-Remnawave-Bedolaga/blob/main/modules/security/firewall.sh#L248-L309) · [Config Profiles](https://docs.rw/learn-en/config-profiles/) · [Host](https://docs.rw/learn-en/hosts/#specify-a-port)
- Базовая защита VPS включает UFW и Fail2Ban для SSH. TrafficGuard остаётся опцией. Для Ubuntu стоит проверять расписание штатных обновлений и использовать SSH-ключи. CrowdSec можно рассматривать при отдельном требовании к централизованной защите. Для блокировки он использует отдельный компонент. [Ubuntu Automatic Updates](https://ubuntu.com/server/docs/how-to/software/automatic-updates/) · [Ubuntu OpenSSH](https://ubuntu.com/server/docs/how-to/security/openssh-server/#ssh-keys) · [CrowdSec](https://docs.crowdsec.net/u/getting_started/intro/)
