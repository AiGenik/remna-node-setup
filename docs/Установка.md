# Установка

## Подготовка

- Отдельный VPS с Ubuntu 24.04 и systemd, архитектура amd64 или arm64.
- Домен ноды. Для self-steal направьте A и используемые AAAA-записи на публичные адреса сетевых интерфейсов VPS. В Cloudflare включите режим DNS only. Проверьте, что внешний firewall пропускает SSH и TCP 80/443.
- В панели откройте «Ноды → Управление → +» и заполните карточку. Мастер подскажет поля и покажет примеры. [Инструкция Remnawave](https://docs.rw/install/remnawave-node/)
- Держите открытым текущий SSH-сеанс и убедитесь, что доступна консоль VPS.

## Мастер

1. Установите команду через `sudo ./install.sh --local` из папки проекта или из GitHub-релиза. Запустите `sudo remna-node-setup`.
2. Выберите «Установить ноду и компоненты». Каждый шаг подсказывает источник поля. Пункт «Подготовка к установке» показывает список заранее.
3. Для self-steal выберите Caddy или Nginx. Caddy получает и продлевает сертификат сам. Nginx использует Certbot через открытый TCP 80. В подтверждениях `[Y/n]` означает «да» по Enter, `[y/N]` — «нет».
4. После установки откройте второе SSH-подключение и подтвердите изменения командой `sudo remna-node-setup confirm`. Первый сеанс оставьте открытым до подтверждения.

| Что запросит мастер | Где взять |
| --- | --- |
| Поддомен ноды | У DNS-провайдера создайте A-запись на публичный IPv4 нового VPS. Тот же поддомен укажите в поле «Домен или IP» в карточке ноды. |
| `NODE_PORT` | Поле `Node Port` в карточке или строка `NODE_PORT` в блоке `environment` после нажатия «Скопировать docker-compose.yml». |
| IP панели | На сервере панели выполните `curl -4fsS https://api.ipify.org && echo`. Если панель выходит с нескольких адресов, укажите их через пробел. |
| SSH-порт и доверенный IP | Мастер предложит параметры текущего подключения, если смог их определить. Доверенный IP — адрес, с которого вы входите на VPS. |
| `SECRET_KEY` | Скопируйте `Secret Key (SECRET_KEY)` вверху карточки или строку `SECRET_KEY` из блока `environment`. Вставьте в терминал и нажмите Enter. Счётчик покажет принятые символы. |

Для standalone-ноды служебный порт доступен из сети только указанным IP панели. VPN-клиенты подключаются по TCP 443. При self-steal требуется TCP 80 для ACME. Порт 8443 слушает только loopback. На панели выберите профиль VLESS TCP REALITY с параметрами из вывода мастера, затем проверьте статус ноды, обычное HTTPS-подключение к домену и подключение тестового VPN-клиента.

## Существующая нода

При обнаружении сторонней установки мастер остановится. Откройте статус текущей ноды в панели и сохраните её Compose, ключ и веб-конфигурацию. Для перехода установите новую ноду на отдельном VPS, проверьте подключение тестового клиента, затем переведите нужный хост в панели на новую ноду. Сохраняйте старую ноду до проверки перехода.
