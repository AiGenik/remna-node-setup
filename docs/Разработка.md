# Разработка и сборка

Серверная часть рассчитана на Ubuntu 24.04 с systemd. Запускайте проверки в отдельной машине Ubuntu, а сквозные проверки Docker, UFW и SSH выполняйте на выделенном тестовом VPS.

## Проверки

В Ubuntu 24.04 установите зависимости и запустите общий набор из корня репозитория.

```bash
sudo apt-get update
sudo apt-get install -y bash curl jq python3 shellcheck
./scripts/check.sh
```

Для проверки реального SSH-транспорта выполните `sudo bash tests/ssh-transport.sh` на отдельной Ubuntu с установленным `openssh-server`. Тест запускает временный `sshd` на loopback.

Набор проверяет синтаксис Bash и ShellCheck, интерфейс в псевдотерминале, заставку `lib/splash.py` (`tests/splash.py`, пропуск по клавише, сигналы и fallback-режимы; предпросмотр — `./remna-node-setup --demo-intro`), DNS, передачу данных по TCP/UDP, выбор портов и настройки компонентов. Тесты обновления и отката используют временные каталоги. В них проверяются контрольная сумма архива и клиентских помощников (`remna-ssh`, `remna-ssh.ps1`), активация релиза и возврат версии. Для Windows PowerShell (5.1 и 7+) отдельно запускается `python tests/windows-launcher.py`.

Для отчёта приложите команду, версию скрипта, версию Ubuntu и обезличенный вывод с ошибкой. Пароли, `Secret Key`, токены и содержимое снимков уберите из отчёта. [GitHub Issues](https://github.com/AiGenik/remna-node-setup/issues)

## Собрать архив

```bash
./scripts/build-release.sh dist
(cd dist && sha256sum -c SHA256SUMS)
```

`dist/remna-node-setup.tar.gz` содержит комплект для установки. `versions.json` задаёт версию, которая должна совпадать с тегом `vX.Y.Z`. Workflow `Release` запускается при публикации тега, выполняет проверки и публикует комплект с `SHA256SUMS`. [Сборки GitHub Actions](https://github.com/AiGenik/remna-node-setup/actions/workflows/release.yml)
