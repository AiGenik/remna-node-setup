# Документация Remna Node Setup

Мастер для Ubuntu 24.04 устанавливает и обслуживает ноды уже работающей панели Remnawave. Каждый раздел можно открыть на GitHub или в хранилище Obsidian `docs`.

## Установить и обслуживать

- [Установка](Установка.md) · подготовка VPS, данные из панели, мастер и входящие порты.
- [Эксплуатация](Эксплуатация.md) · диагностика связи, подтверждение SSH, обновления и восстановление.
- [Psiphon](Psiphon.md) · локальный SOCKS5 и шаблон маршрутизации Gemini.

- [Архитектура](Архитектура.md) · модули, файлы конфигурации и сетевые транзакции.
- [Источники](Источники.md) · документация и проекты, на которые опирается мастер.
- [Журнал разработки](Журнал%20разработки.md) · изменения и результаты проверок по версиям.
- [Аудит 0.4.0](Аудит%200.4.0.md) и [аудит 0.5.0](Аудит%200.5.0.md) · исторические замечания к этим выпускам.
